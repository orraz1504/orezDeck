## הסכמה

```json
{
  "deck": "שם הקורס או הנושא",
  "cards": [
    { "type": "basic", "front": "שאלה", "back": "תשובה", "tags": ["נושא"] },
    { "type": "cloze", "text": "משפט עם {{c1::חלק מוסתר}} ועוד {{c2::חלק}}", "back": "הערה לצד התשובה (לא חובה)", "tags": ["נושא"] },
    {
      "type": "problem",
      "group": "שם סוג הבעיה, למשל t-test",
      "front": "כותרת קצרה לבעיה",
      "tags": ["נושא"],
      "variants": [
        {
          "front": "נוסח הבעיה עם הנתונים",
          "steps": [
            { "title": "כותרת השלב", "body": "מה עושים בשלב, עם נוסחה" }
          ]
        }
      ]
    }
  ]
}
```

- `type` הוא אחד מ-`basic`, `cloze`, `problem`.
- ב-`cloze`: כל מספר `cN` הופך לכרטיס נפרד. מספר שחוזר כמה פעמים (`{{c1::…}}` פעמיים) מוסתר באותו כרטיס. רמז אופציונלי: `{{c1::תשובה::רמז}}`.
- `tags`: 1–3 תגיות קצרות לפי נושא בחומר. אותו נושא תמיד באותו ניסוח.
- נוסחאות ב-LaTeX: `$...$` בתוך שורה, `$$...$$` בשורה נפרדת. ב-JSON יש לכתוב לוכסן כפול: `"$\\frac{a}{b}$"`.
- עיצוב קל מותר: `**הדגשה**`, רשימות עם `- `, מעבר שורה עם `\n`, טבלה קטנה `| $n = 36$ | $\\bar{x} = 128$ |`.
- שפה: כמו בחומר (בדרך כלל עברית). מונחים מקצועיים באנגלית כמו שהם מופיעים בחומר, למשל "ה-cardiac output".

## כללים לכרטיסים טובים

1. **עובדה אחת בכל כרטיס.** אם התשובה דורשת יותר ממשפט או שניים, פצל לכמה כרטיסים.
2. **שאלה חד-משמעית.** צריכה להיות לה תשובה נכונה אחת שאפשר לבדוק. לא "ספר על…" אלא "מה תפקיד…", "מה ההבדל בין X ל-Y?", "מה קורה ל-X כש-Y עולה?".
3. **תשובה קצרה.** מה שצריך לזכור, בלי הקדמות. הסבר קצר "למה" מותר בשורה נפרדת.
4. **cloze לרשימות, לשלבים בתהליך, להגדרות ולמשפטים מרכזיים.**
   - רשימה של 4 פריטים = טקסט אחד עם `c1`–`c4`, כרטיס לכל פריט.
   - תהליך בשלבים = משפט לכל שלב, עם השלב המוסתר.
   - אל תסתיר מילים טריוויאליות. הסתר את המונח או המספר שצריך לזכור.
5. **בלי כפילויות.** אל תשאל את אותה עובדה פעמיים באותו ניסוח. כיוון הפוך (מונח → הגדרה ↔ הגדרה → מונח) רק למונחים חשובים במיוחד.
6. **בלי כרטיסי כן/לא** ובלי "נכון או לא נכון". הפוך אותם לשאלה פתוחה.
7. **הקשר בשאלה:** אם מונח מופיע בכמה הקשרים, ציין את ההקשר ("בכליה, מה…").
8. **הכל מהחומר.** אל תמציא עובדות, מספרים או מקורות שלא מופיעים בו.

## למקצועות חישוביים (סטטיסטיקה, פיזיקה, כימיה, כלכלה, הנדסה)

בנוסף לכרטיסים הרגילים צור שלושה סוגים:

1. **כרטיסי נוסחה** (`basic`): בשאלה, מה הנוסחה מחשבת ומתי משתמשים בה. בתשובה, הנוסחה ב-LaTeX ומשמעות כל סימן.
   דוגמה: `"front": "נוסחת סטטיסטי המבחן z לממוצע (σ ידועה)"`, `"back": "$$z = \\frac{\\bar{x} - \\mu_0}{\\sigma/\\sqrt{n}}$$\nσ: סטיית התקן באוכלוסייה, n: גודל המדגם"`.
2. **כרטיסי "איזו שיטה מתאימה?"** (`basic`): תיאור קצר של מצב, ובתשובה שם השיטה והסיבה במשפט אחד.
   דוגמה: `"front": "שני מדגמים בלתי תלויים, σ לא ידועה, n = 12 בכל קבוצה. איזה מבחן?"`, `"back": "מבחן t לשני מדגמים בלתי תלויים, כי σ לא ידועה והמדגמים קטנים."`.
3. **כרטיסי בעיה** (`problem`): לכל סוג בעיה מרכזי בחומר, כרטיס אחד עם **3–4 וריאציות**.
   - כל וריאציה היא אותה בעיה עם נתונים אחרים (ולפעמים כיוון אחר, למשל חד-צדדי או דו-צדדי).
   - `front` של הווריאציה: הבעיה המלאה עם כל הנתונים. אפשר להוסיף טבלה קטנה עם הנתונים.
   - `steps`: פתרון מלא בשלבים, 2–5 שלבים, כל אחד עם `title` קצר ו-`body` עם החישוב. בדוק שהחישובים נכונים.
   - `group`: שם סוג הבעיה, זהה בכל הכרטיסים מאותו סוג.
